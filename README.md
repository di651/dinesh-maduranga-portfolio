# Dinesh Maduranga — Mechanical Engineering Portfolio

Professional portfolio focused on mechanical design, CAD drafting, FEA / engineering analysis, automation and manufacturing.

## Website source committed
- `index.html` — portfolio content, including the editable hero photo control
- `styles.css` — website styling
- `script.js` — photo and text editor behaviour
- `.github/workflows/pages.yml` — builds and deploys the website to GitHub Pages

## Add the project images and résumé
The website refers to files inside `assets/`. I prepared a single archive containing the supplied project photos, CAD / CFD images and CV.

1. Download `portfolio-assets.zip` from the ChatGPT conversation.
2. In this repository, select **Add file → Upload files**.
3. Upload `portfolio-assets.zip) to the repository root and commit it to `main`.

The Pages workflow automatically extracts the archive into the website build. The ZIP itself is not included in the published site.

## Enable GitHub Pages (one-time setting)
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **GitHub Actions** as the source.

After the assets archive is uploaded and Pages is enabled, the project site address will be:
https://di651.github.io/dinesh-maduranga-portfolio/

## Editing notes
- The photo editor saves replaced photos in the current browser on the current device. It does not publish those local edits automatically.
- The text editor saves wording changes locally in browser storage. Use its export function to keep a backup.
- To make final photo or wording changes public, update the corresponding repository files.

## Before publishing
- Confirm that your email address and phone number are suitable for public display.
- Obtain permission before publishing employer / customer project visuals or internal details. Some supplied Brandix technical drawings carry confidentiality and copyright notices; publish only approved or redacted visuals.
- Check that every project description accurately reflects your personal contribution.
